# Dr. Elena Marceau — Neurology portfolio

An editorial, responsive neurologist practice website built with React, Vite, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL when the development server is ready (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

This is a frontend demo. Replace the illustrative doctor profile, credentials, contact details, hours, and stock imagery with verified practice information. The appointment form only displays a local preview confirmation; connect it to an approved secure booking service before collecting patient information.

## Page structure

- `src/pages/` contains the home, practice, specialties, journey, and visit pages.
- `src/sections/` contains the independently composed page sections.
- `src/components/` contains shared navigation, footer, branding, and layout elements.
- `src/data/content.js` holds the navigation, specialty, and journey content.
